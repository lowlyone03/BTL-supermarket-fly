  Cú pháp
    /ask <câu hỏi tiếng Việt>
    /ask  (không arg) → 1 tin hướng dẫn, không gọi LLM:
      “Gõ /ask rồi câu hỏi, ví dụ /ask hôm nay cần chú ý gì?
       Trợ lý không duyệt chứng từ. Việc chờ: nút trên tin, hoặc /pending.”

  Không
    Không biến mọi tin chữ thường thành /ask (đụng luồng nhập lý do từ chối
    peekReject + unknownCmd + bàn phím reply).

  Độ dài

    Trả lời: splitTelegramText(answer, 3900) — Bot API ~4096/tin.

  Typing

  Trả lời mẫu (bị chặn duyệt)

1.3. Xác thực — OTP đã link, không JWT trên chat, không tin “tôi là QL”

    { MaNV, MaTK, MaVaiTro, TenVaiTro, TenNV }

    3. isManagerRole — CODE hiện tại lệnh bot = QL. /ask theo đúng cửa đó.
       (Plan 07/09 từng 5 actor; CODE 10/09 bind+lệnh chỉ QL. Không nới
        5 actor trong sprint /ask.)
    4. codesOf(user) từ TenVaiTro trên DB, không từ nội dung tin.
    5. KHÔNG mint JWT, KHÔNG gửi token lên Telegram, KHÔNG tin câu
       “tôi là kế toán / cho xem UC37”.
    6. Truyền user đó vào assistantService.ask({ user, question, req: null }).
       logAuditSafe đã chịu user không có req (DiaChiIP trống).

1.4. Reuse LLM — một não

  telegramBotController.parseCommand thêm:
    /^\/ask(?:\s+(.+))?$/i  → { name: 'ask', arg }

  runCommand case 'ask':
    CẤM gọi loadTodayBundle / telegramApprove / cmdToday.
    Gọi:
      const { ask } = require('../services/assistantService');
      return ask({ user, question: arg, pool, channel: 'telegram' });

  Sửa ask() tối thiểu:
    - channel: 'electron' | 'telegram' (mặc định electron) để ghi lịch sử
    - tab: 'chat' | 'homnay' (Telegram = chat, trừ khi câu khớp “hôm nay”)

  Không fetch http://127.0.0.1:3000/api/assistant/ask từ bot (JWT lồng, timeout).

1.7. Webhook vs polling vs timeout Telegram

  Bot API webhook: server nên HTTP 200 nhanh; xử lý lâu → Telegram retry
  (cửa sổ thực tế vài chục giây, không phải phút).

  /today SELECT nhanh = ổn. /ask + CodeCraft 25s + 5 tool × 2s = có thể
  sát/vượt cửa sổ.

  Chốt P2-ĐỦ
    Nhánh ask: gửi ngay 1 tin “Đang hỏi trợ lý Fly…” rồi chạy ask()
    không chặn return của handleUpdate (setImmediate / queue microtask).
    Webhook res.json ngay sau khi đã enqueue.
    Polling: cùng enqueue (tránh getUpdates 25s bị chiếm 25s LLM).
    ASSISTANT_TIMEOUT_MS giữ 25000; nếu quá hạn → sendMessage tiếng Việt
    “Trợ lý tạm không trả lời kịp — mở dashboard Electron hoặc /today /pending.”
    Không 500 xuyên POS. try/catch fire-and-forget như telegramNotify.

  TELEGRAM_WEBHOOK_URL vẫn quyết định webhook|polling. /ask không đổi mô hình đó.
  Vẫn deleteWebhook trước getUpdates.
