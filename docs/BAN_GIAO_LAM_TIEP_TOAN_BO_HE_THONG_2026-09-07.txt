5. KHÔI PHỤC DATABASE
================================================================================

5.1. SSMS (khuyến nghị)

  1. Mở SSMS, kết nối localhost\SQLEXPRESS bằng Windows Authentication.
  2. Chuột phải Databases → Restore Database...
  3. Device → chọn file:
       SupermarketFlyDB_2026-09-07_191855.bak
  4. Tên database đích: SupermarketFlyDB
  5. Nếu máy đã có DB cùng tên: backup cái cũ trước, rồi ghi đè khi chắc.
  6. Nếu SQL báo không đọc được .bak: chép file vào thư mục backup mặc
     định của SQL Server rồi chọn lại.

5.2. sqlcmd (nếu quen SSMS)

  sqlcmd -S localhost\SQLEXPRESS -E -C -Q "RESTORE DATABASE [SupermarketFlyDB] FROM DISK = N'D:\duong-dan\SupermarketFlyDB_2026-09-07_191855.bak' WITH REPLACE"

  Thêm -C vì ODBC Driver 18 trên một số máy bắt SSL.

5.3. Kiểm tra sau restore

  USE SupermarketFlyDB;
  SELECT DB_NAME() AS TenDatabase;
  SELECT
    (SELECT COUNT(*) FROM NhanVien)  AS NhanVien,
    (SELECT COUNT(*) FROM SanPham)   AS SanPham,
    (SELECT COUNT(*) FROM HoaDon)    AS HoaDon,
    (SELECT COUNT(*) FROM TaiKhoan)  AS TaiKhoan;

  Kỳ vọng bản này: 13 / 36 / 10 / 12.

5.4. CẤM sau khi restore bản backup MỚI NHẤT

  KHÔNG chạy:  npm run setup:next
  Lệnh đó dành cho máy TRẮNG / DB cũ cần nâng cấp. Nó sẽ migrate + seed
  + dọn dữ liệu demo và CÓ THỂ ĐỔI dữ liệu test trong .bak.

  Máy trắng (không dùng .bak): tạo DB bằng
    server/migrations/SupermarketFly_CreateDB.sql
  rồi mới  npm run setup:next

QUY TRÌNH 1 — MUA / NHẬP
  TK đếm thật → hết/thiếu mới đề nghị (KHÔNG cần QL duyệt đề nghị)

QUY TRÌNH 2 — BÁN / QUỸ CA
  QL công bố lịch → TN đúng ngày + trong giờ (vào sớm tối đa khoảng 10 phút)

  → QL duyệt từng người hoặc Duyệt tất cả  (duyệt CHƯA trả)

  → KT chi từng NV; chuyển khoản bắt buộc mã giao dịch; thất bại thì làm lại cùng phiếu.
  Bảng lương KHÔNG trừ vào lãi gộp.
  P&L điều hành (màn QL, code 10/09): KQKD = lãi gộp − lương khóa − cước;

  6. Migration mới: file SQL chạy lại được, tên
       SupermarketFly_Migration_YYYYMMDD_TenNgan.sql
     Thêm vào cuối script migrate:next trong server/package.json.
  7. Thêm UC: thống nhất mã trong permissions.js, seed lại quyền.
  8. Test kèm: thêm node --check hoặc test-*.js, gắn vào npm test
     nếu liên quan tiền / tồn / nợ / ca.
  9. Tiền tố dữ liệu test: TEST-<TEN>-<YYYYMMDD>
 10. Không xóa dữ liệu người khác trên database chung.

Chuỗi bắt buộc phải chạy CHUNG (không ai "xong một mình"):

  MUA : TK đề nghị → MH lập đơn → QL duyệt → MH tạo chuyến → TK nhập
        → KT đối chiếu → KT phiếu chi → QL duyệt/giao quỹ NCC
        → KT thanh toán.

        → KT phiếu thu.

  ĐỔI : TN lập → TK kiểm → QL duyệt → TN hoàn tất

  LƯƠNG: QL lịch + lễ → nhân viên chấm → QL duyệt công → KT lập + khóa
         → KT lập phiếu → QL duyệt + giao 1 quỹ → KT chi.
