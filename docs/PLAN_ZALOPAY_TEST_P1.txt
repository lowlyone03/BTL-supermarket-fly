3. Invariant 4.7 — INSERT rồi mới create
----------------------------------------
1) Kiểm HĐ Nháp + remaining + không có QR Chờ (mọi NguonXacNhan)
2) Sinh MaTT + app_trans_id
3) INSERT ThanhToan Chờ xác nhận, NguonXacNhan=ZaloPay, MaThamChieuCong=app_trans_id
4) COMMIT local
5) Gọi ZaloPay POST /v2/create (HMAC key1: app_id|app_trans_id|app_user|amount|app_time|embed_data|item)
6) return_code=1 → trả QR / order_url (đơn đã tạo, chưa thanh toán)
7) Fail RÕ → UPDATE đúng dòng Thất bại (clearFailure=true)

3b. Invariant 4.7b — uncertain ≠ failure (clearFailure)
-------------------------------------------------------
clearFailure=true CHỈ khi:
  (a) lỗi config local (thiếu ZALOPAY_APP_ID/KEY1/KEY2, thiếu IPN/return URL,
      app_trans_id sai format, trỏ production), HOẶC
  (b) ZaloPay xác nhận request bị từ chối cuối cùng (return_code === 2).

HTTP 4xx và body parse được → CHƯA đủ để clearFailure=true.
Phải kèm xác nhận request bị từ chối cuối cùng (return_code === 2).
Ví dụ: HTTP 400 + return_code 2 → Thất bại.
      HTTP 400 + body parse + return_code 1 / mã lạ / thiếu return_code → GIỮ Chờ + Query.
Không hiểu mọi 4xx là final.

HTTP 5xx / timeout / mất mạng / body không parse → GIỮ Chờ, POS bấm Query lại.
Lý do: IPN có thể tới trước khi INSERT nếu gọi ZaloPay trước.

8. API — bảng controller IPN
----------------------------
Public (app.js, TRƯỚC 404):
  GET  /api/payments/gateway/return  → HTML UX

  POST /api/payments/gateway/ipn
  Luôn HTTP 200 + JSON { return_code, return_message }. Không 204 như MoMo.
  ZaloPay retry khi return_code === 0; mã khác thì dừng.

  Case (paymentGatewayController.ipn)                 | HTTP | return_code | return_message | ZaloPay retry?
  ----------------------------------------------------|------|-------------|----------------|---------------
  type !== 1 (không phải Order) → ignore, không apply | 200  | 1           | ignored        | KHÔNG
  Idempotent: keep_success / retry_complete / ignore  | 200  | 1           | success        | KHÔNG
    / transid_conflict / invoice_cancelled            |      |             |                |
  first_success / mark_failed / amount_mismatch xong  | 200  | 1           | success        | KHÔNG
  MAC/schema sai (thiếu data, JSON, zp_trans_id)      | 200  | -1          | mac not equal  | không tin callback
  Exception / order_not_found (IPN sớm hơn INSERT)    | 200  | 0           | ...            | CÓ (~3 lần)

  CẤM trả return_code 0 cho ignore hoặc idempotent — ZaloPay callback lại không cần thiết.
  Helper: ipnIgnored / ipnIdempotent / ipnAck → 1; ipnBadMac → -1; ipnRetry → 0.

JWT cashierRoutes (UC25):
  POST /api/cashier/invoices/:id/payments/qr
  GET  /api/cashier/invoices/:id/payments/:maTT
  POST /api/cashier/invoices/:id/payments/:maTT/query
  POST /api/cashier/invoices/:id/payments/:maTT/fail
